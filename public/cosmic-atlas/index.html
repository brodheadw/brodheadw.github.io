Public catalog downloads
DESI DR1 redshifts · IceCube IceTracks DR2 (2008–2022) · Fermi 4FGL-DR4
FITS/catalog archives must first be exported to CSV. For DESI, include RA, DEC, Z and ideally ZWARN/SPECTYPE; this viewer uses a cosmological distance approximation for redshift objects.
Galaxy columns: name, ra_deg, dec_deg, distance_mpc, distance_kpc, or z (redshift). IceCube: ra_deg, dec_deg, optional angular_error_deg, energy_gev. Fermi: Source_Name, RAJ2000, DEJ2000. Source catalogs are directions, not measured distances. Import limit: 80k galaxies, 30k events, 15k Fermi sources; rendered neutrino sightlines are capped for speed. All imported data remain local to this browser tab.
Scientific caveats & sources
These are approximate literature values for a curated set of nearby galaxies (not a comprehensive survey). The Sun is the origin, not the Galactic center. Boötes III is a disrupting stellar system/dwarf-galaxy candidate, and its classification is debated. A neutrino direction is an angular line of sight, not a measured source distance or evidence of dark matter. No IceCube or Fermi observations are preloaded. DESI redshift distance approximations assume a flat ΛCDM model (H0=70 km/s/Mpc, Ωm=0.3), and are unsuitable for precision cosmology or flow-corrected nearby distances. Angular matches are not detections and need exposure/background analysis.
