These are historical verification fixtures, never a current satellite snapshot.

- `vallado-sgp4.json`: all 33 published input blocks from Vallado, Crawford, Hujsak & Kelso (2006), AIAA 2006-6753. Numerical inputs are from CelesTrak's [SGP4-VER.TLE](https://github.com/CelesTrak/fundamentals-of-astrodynamics/blob/main/datalib/SGP4-VER.TLE). Expected improved-mode C++ vectors are the published `tcppver.out`, mirrored by the [python-sgp4 maintainer](https://github.com/brandon-rhodes/python-sgp4/blob/master/sgp4/tcppver.out). 666 successful vectors plus one deliberately invalid orbit; the final block tests deep-space propagation after 1,844,000 minutes.
- `jpl-horizons.json`: fetched 2026-11-12 directly from NASA/JPL Horizons. Each case records the exact query. ICRF geometric vectors, Sun-centred for planets and Earth-centred for the Moon, KM-S units, no light-time/aberration correction. Three dates: 2000-01-01, 2026-11-12, 2050-01-01. TDB input differs from the matching TT date by less than 2 ms; that difference is below the library's 1-arcminute accuracy goal. Leap-second offset for 2050 uses the currently known 37-second TAI−UTC value.
- `astropy-frames.json`: generated offline with Astropy 8.0.2, ERFA and bundled IERS Earth-orientation data. Includes each UT1−UTC and polar-motion input. GCRS reference uses full IAU 2006/2000A; the application deliberately reports its reduced IAU2000B conversion as approximate. ITRS follows Vallado's GMST1982 + polar-motion convention. A 7348 km test radius magnifies frame errors enough to check signs and equinox rotations.
- `skyfield-passes.json`: generated offline with Skyfield 1.55 and python-sgp4 2.27 using the historical ISS example TLE published in [Astropy's satellite documentation](https://docs.astropy.org/en/stable/coordinates/satellites.html). Includes 21 complete geometric horizon passes over New York, London and Sydney on 2019-12-09. Skyfield used its built-in timescale (included UT1−UTC values), no polar motion and no atmospheric refraction. OMM was exported from the same TLE with python-sgp4.

Library licenses are retained with the vendored libraries. Numerical source citations are retained in the fixture JSON headers. Fixtures are small reproducible numerical references; they are never advertised as live observations.
